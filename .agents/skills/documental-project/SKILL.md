# documental-project

Lee las [instrucciones del ámbito](../../../AGENTS.md) y abre desde el [README](../../../README.md) la guía del contrato o de operación relevante.

1. Identifica el recorrido afectado en la arquitectura y elige las guías de los componentes que lo implementan.
2. Cuando cambien inicialización, servicios o configuración, valida tanto Compose base como el perfil sintético de entrega con la plantilla de entorno.
3. Relaciona cada resultado con su revisión o imagen. Para validar con dos usuarios y proveedores simulados usa la guía de entrega.

Para ejecutar la verificación integral, abre la [guía de entrega](../../../docs/release/README.md).
