# Reportar vulnerabilidades

El entorno soportado es una demo local en loopback; este Compose no está validado para exposición pública a Internet. Los resultados fechados de imágenes y sus limitaciones están en [verificación de entrega](docs/release/README.md).

No publiques secretos, documentos privados, tokens ni una explotación detallada en una issue pública. Si está habilitado, utiliza **Report a vulnerability** en la pestaña **Security** de GitHub para un reporte privado. Si ese canal no está disponible, solicita al mantenedor un canal privado mediante una issue sin detalles sensibles antes de enviar la reproducción. No se garantiza un plazo de respuesta.

Incluye versión o commit, componente, pasos mínimos con datos sintéticos, resultado esperado/observado e impacto. No pruebes contra instalaciones o datos de terceros. Conserva las claves y credenciales reales fuera de Git, capturas y logs.
