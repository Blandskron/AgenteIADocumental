Tus documentos. Tu conocimiento. Tu inteligencia artificial.

Blandskron Documental es una plataforma open source para organizar, buscar y analizar documentos mediante RAG híbrido con citas verificables, control de acceso multiempresa y libertad para elegir entre Groq en la nube u Ollama local en tu propio hardware.

Capacidades verificadas

Diseñado para equipos que exigen trazabilidad y control

Cada funcionalidad listada corresponde a código real, contratos versionados y suites automatizadas en la rama develop.

RAG híbrido con citas verificables

Combina búsqueda vectorial pgvector (HNSW) con búsqueda léxica FTS fusionada mediante Reciprocal Rank Fusion (RRF), delimitación anti prompt-injection y referencias clicables [Fuente N].

Gestión documental e ingesta

Soporte para PDF, DOCX, TXT, Markdown (frontmatter, wikilinks y lotes ZIP seguros) e imágenes con OCR. Embeddings locales en CPU con idempotencia por hash SHA-256.

Control de acceso multiempresa

Identidad JWT RS256, roles de privilegios mínimos en PostgreSQL, aislamiento por empresa/área/grupo, registro inicial transaccional y Google Login OIDC opcional.

Flujos documentales y auditoría

Asignación de documentos, notificaciones internas, aceptación, rechazo, registro interno de firma y visor administrativo de auditoría en /admin/audit.

Proveedores IA sin reinicios

Alterna entre Groq (clave cifrada con secrets1.) y Ollama local con catálogo CPU autorizado desde /settings/ai.

Knowledge Studio y MCP de solo lectura (opcional)

Perfil opcional --profile studio para generar artefactos versionados en studio.artifacts, exportación CSV/PDF segura, estudio offline SM-2 y servidor MCP JSON-RPC 2.0 autenticado con el JWT del usuario.

Orquestación Agéntica y Code Mode en sandbox (opcional)

Perfiles opcionales --profile agents y --profile code-mode con grafo multi-paso, checkpoints estrictos en agents.*, aprobación humana explícita (Human-in-the-Loop), análisis determinista de riesgos/vencimientos y ejecución aislada en Deno --deny-all sin salida a internet ni secretos.

Inteligencia artificial flexible

Elige entre velocidad en la nube o privacidad local

Los embeddings se calculan siempre localmente en CPU. Para la generación de respuestas, cada empresa elige su proveedor desde /settings/ai sin tocar archivos ni reiniciar servicios.

Servicio externo opcional

Groq (Nube)

  • Configura tu propia API key desde la web; se guarda cifrada con secrets1. y nunca vuelve al navegador.
  • Consulta modelos disponibles, ajusta parámetros y prueba la conexión en vivo.
  • La pregunta y los fragmentos autorizados se envían a Groq; sus cuotas y límites dependen de las condiciones del proveedor.
Ejecución local opcional

Ollama (Local en CPU)

  • Sin API key comercial y sin enviar contenido documental a terceros una vez descargado el modelo.
  • Catálogo CPU curado (gemma2:2b, qwen2.5:3b, llama3.2:3b, phi3:mini, mistral:7b) con descarga controlada y progreso en vivo.
  • Requiere RAM (4–12 GB según modelo), CPU y espacio en disco local; se habilita con el perfil --profile local-llm.

Instalación rápida

En marcha con Docker Compose en minutos

Requisito previo: tener instalado Git y Docker Desktop / Docker Engine con Compose v2. Nota: la disponibilidad y el licenciamiento de Docker Desktop dependen del entorno y tamaño de organización; en Linux puede usarse Docker Engine open source.

Modo básico (Linux, macOS y Windows PowerShell) 
git clone https://github.com/Blandskron/AgenteIADocumental.git
cd AgenteIADocumental
docker compose up -d --build
  1. Sin .env obligatorio: secrets-init genera secretos aleatorios fuertes en un volumen persistente (runtime_secrets) respetando cualquier .env previo.
  2. Abre la aplicación: entra en http://localhost:3000 y crea la primera cuenta administradora desde la pantalla de configuración inicial.
  3. Configura la IA: abre /settings/ai para ingresar tu clave de Groq o activar Ollama local con docker compose -f compose.yaml -f docker/compose/ollama.yml --profile local-llm up -d.

Arquitectura real

Microservicios desacoplados con mínimos privilegios

Publicación en loopback (127.0.0.1) por defecto, roles dedicados de PostgreSQL por servicio y verificación de permisos en el servidor antes de cualquier recuperación o generación.

1. Frontend (React 19 + TypeScript + Nginx)

Puerto 3000. Interfaz responsiva y accesible, contenedor solo lectura sin privilegios.

2. Identidad y Auditoría (Django REST Framework)

AuthServices (8001): JWT RS256, multiempresa, Google OIDC opcional, configuración IA y audit_logs.

3. Dominio Documental, RAG y Agentes (FastAPI + Deno Sandbox)

Ingesta E5 + OCR (8003), Chat RAG híbrido (8002), Búsqueda FTS (8004), Acceso/Flujos (8005), Biblioteca (8006), Transferencias (8007), Conversaciones (8008), Perfil (8015), Exportación PDF (8016), Drive opcional (8017), Studio/MCP opcional (8018) y Orquestador Agéntico + Code Sandbox Deno --deny-all opcional (8019).

4. Datos y Proveedores IA

PostgreSQL 16 + pgvector (HNSW) + pg_trgm + volumen de originales, más Groq u Ollama local.
